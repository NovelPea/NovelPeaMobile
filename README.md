# NovelPea Mobile

NovelPea Mobile is a mobile-first writing studio for drafting novels, organizing story ideas, and browsing published stories. It also works on desktop browsers.

## Features

- Create a demo account or log in
- Draft multiple novels and organize them by chapter
- Automatically save writing in your browser, with an option to disable autosave
- Use the Story Bible, Characters, Places, and Notes sections
- Track word and character counts
- Format manuscript text with bold, italic, underline, strikethrough, headings, and bulleted or numbered lists
- Undo and redo editor changes
- Adjust editor font size and line spacing
- Edit profile details, including bio, location, website, and writing interests
- Publish novels with a cover, descriptions, and genres
- See published novels in Discover and browse their descriptions and table of contents
- Export the active manuscript as a plain-text `.txt` file
- Switch between light and dark themes
- Navigate on mobile using the slide-out menu

## Getting started

1. Save the app HTML as `index.html`.
2. Open `index.html` in a modern mobile or desktop browser.
3. Create an account or log in.

No installation or server is required.

## Publishing and Discover

In this standalone demo, published novels appear in Discover **only in the same browser where they were published**. The app does not connect to a shared server, so novels are not visible to other people or devices.

## Saving and privacy

This demo stores account and writing data in your browser using `localStorage`. Data stays in that browser on that device. Clearing browser storage may delete it. **Do not use a real password or enter sensitive personal information.** This demo does not use a secure server.
