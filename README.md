# NovelPea Mobile

NovelPea Mobile is a mobile-first writing studio for drafting novels, creating comic books, organizing story ideas, and browsing published stories. It also works on desktop browsers.

## Features

- Create a demo account or log in
- Create multiple novels, short stories, novellas, and comic books
- Organize manuscripts into chapters
- Automatically save writing in your browser, with an option to disable autosave
- Use the Story Bible, Characters, Places, and Notes sections
- Track word and character counts
- Format manuscript text with bold, italic, underline, strikethrough, headings, and bulleted or numbered lists
- Undo and redo editor changes
- Adjust editor font size and line spacing
- Edit profile details, including bio, location, website, pronouns, and writing interests
- Build comics with pages and panels, uploaded artwork, captions, and dialogue
- Publish novels and comics with covers and descriptions
- Choose genres including Brainrot, Meme Comedy, Surreal Brainrot, Internet Culture, Gen Alpha Humor, and Chaotic Comedy
- Browse published stories in Discover, including descriptions and tables of contents
- Export the active manuscript as a plain-text `.txt` file
- Switch between light and dark themes
- Navigate on mobile using the slide-out menu

## Getting started

1. Save the app HTML as `index.html`.
2. Open `index.html` in a modern mobile or desktop browser.
3. Create an account or log in.

No installation or server is required.

## Publishing and Discover

Published novels and comics are saved in the browser where they were published. Discover shows public published books in that same browser. The app has no shared server, so books aren’t available to other people or devices.

Novel publishing requires at least **3 chapters** and **2,500 words**. Comic books can be published through the comic publishing form.

## Saving and privacy

This demo stores account, profile, and writing data in your browser using `localStorage`. Data stays in that browser on that device; clearing browser storage may delete it. Uploaded cover and panel images are stored with the book data in the browser.

**Do not use a real password or enter sensitive personal information.** This demo does not use a secure server.
