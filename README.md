# NovelPea Mobile

NovelPea Mobile is a mobile-first writing studio for drafting novels and organizing story ideas. It also works on desktop browsers.

## Features

- Create an account or log in
- Take a skippable tutorial when creating an account
- Choose preferred genres after the tutorial, or skip genre selection
- Draft and organize a novel by chapter
- Automatically save your work in your browser
- Use the Story Bible, Characters, Places, and Notes sections
- Track word and character counts
- Format selected text as bold, italic, or underlined
- Edit your full name, bio, and birthplace in your profile
- Keep your pen name and account details locked after signup
- Export your manuscript as a plain-text `.txt` file
- Switch between light and dark themes
- Navigate on mobile using the slide-out menu

## Getting started

1. Save the app HTML as `index.html`.
2. Open `index.html` in a modern mobile or desktop browser.
3. Create an account or log in.

No installation or server is required.

## Saving and privacy

This demo stores account and writing data in your browser using `localStorage`. Data stays in that browser on that device. Clearing browser storage may delete it. **Do not use a real password or enter sensitive personal information.** This demo does not use a secure server.
